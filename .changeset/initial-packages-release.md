Initial modular package extraction release (v0.1.0):
- **openrouter-resilient-client**: Exponential retries, fallback failover models, timeouts, and clean JSON extraction.
- **express-ai-guard**: Dual-tier rate limiting (IP + user), request IDs, and production-safe error shielding.
- **react-calendar-heatmap-streaks**: Generic contribution heatmap with 4 intensity levels, timezone safety, and streak analytics.
- **react-workout-tracker**: Tactile set-logging UI, rest countdown timer, and headless workout session hook.
- **react-motion-presets**: Framer Motion stagger animations, animated count-up numbers, AI streaming word reveal, and collapsible cards.
- **fitness-utils**: Fitness calculations (BMI, macros, MET burn), RFC-compliant CSV export, Web Audio chime, Web Speech hooks, and PDF reporting.
- **ai-nutrition-estimator**: Multimodal nutrition analysis, exercise calorie estimation, versioned prompts, and TTL response cache.
