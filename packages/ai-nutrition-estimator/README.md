# @jashan-randhawa/ai-nutrition-estimator

AI-powered estimation engine for nutrition tracking and exercise energy expenditure. Converts meal text descriptions and dish photographs into calories and macronutrients, and activities into MET-based calories burned with strict schema validation and response caching.

> **Medical Disclaimer**: All outputs generated by this package are estimates for informational and tracking purposes only and should not be used as medical advice or clinical dietary prescriptions.

## Features

- 🥗 **Text-to-Nutrition**: Turns freeform dish names or meal notes into structured macros (`calories`, `protein`, `carbs`, `fat`).
- 📷 **Photo-to-Nutrition**: Multimodal image analysis identifying meals and estimating visible portion nutrition.
- 🏃 **MET-Based Energy Expenditure**: Calculates calories burned using scientific MET (Metabolic Equivalent of Task) values tailored to body weight and duration.
- ⚡ **5-Minute TTL Cache**: In-memory response cache keyed on query signatures to prevent duplicate calls and conserve API credits. Pluggable for Redis.
- 🛡️ **Robust Output Sanitization**: Strips markdown formatting, code fences, and thought tags before schema parsing.

## Installation

```bash
npm install @jashan-randhawa/ai-nutrition-estimator
```

## Quick Start

```typescript
import { createEstimator } from '@jashan-randhawa/ai-nutrition-estimator';
import { createOpenRouterClient } from '@jashan-randhawa/openrouter-resilient-client';

const ai = createOpenRouterClient({ apiKey: process.env.OPENROUTER_API_KEY });
const estimator = createEstimator({ chat: ai.chat });

// 1. Food from Text
const meal = await estimator.foodFromText('Grilled salmon fillet with brown rice and broccoli');
console.log(meal.calories, meal.protein, meal.carbs, meal.fat);

// 2. Activity Calorie Burn
const workout = await estimator.activity({
  name: 'Outdoor cycling at moderate pace',
  minutes: 45,
  weightKg: 75,
});
console.log(`${workout.calories_burned} kcal (MET: ${workout.met_value})`);

// 3. Food from Photo
const photoEstimate = await estimator.foodFromImage({
  base64: '...',
  mimeType: 'image/jpeg',
});
```

## Options Table

| Option | Type | Default | Description |
|---|---|---|---|
| `chat` | `Function` | Required | Completion function receiving `{ messages, title, maxTokens }` |
| `cache` | `EstimatorCache` | `MemoryCache` | Custom cache store (e.g. Redis) |
| `ttlMs` | `number` | `300000` (5m) | Cache expiration window in milliseconds |
| `disclaimer` | `string` | Built-in | Custom disclaimer attached to estimation payloads |
